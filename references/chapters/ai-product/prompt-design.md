# Prompt设计

## 概览
Prompt设计章节用于设计产品中AI能力的Prompt，明确Prompt的设计原则、模板、示例等。

---

## 核心内容

### Prompt类型
- **系统Prompt**：定义AI的角色和任务
- **用户Prompt**：用户的输入和请求
- **上下文Prompt**：提供上下文信息
- **示例Prompt**：提供示例和参考

### Prompt设计原则
- **明确性**：Prompt应清晰明确，避免歧义
- **简洁性**：Prompt应简洁，避免冗余
- **结构性**：Prompt应有清晰的结构
- **可扩展性**：Prompt应易于扩展和修改

### Prompt优化方法
- **迭代优化**：通过多次迭代优化Prompt
- **示例驱动**：通过示例优化Prompt
- **反馈驱动**：通过用户反馈优化Prompt

---

## 填充指南

### 步骤1：明确Prompt需求
- 分析产品中AI能力的使用场景
- 明确每种场景的Prompt需求
- 明确Prompt的性能指标

### 步骤2：设计Prompt模板
- 设计系统Prompt模板
- 设计用户Prompt模板
- 设计上下文Prompt模板
- 设计示例Prompt模板

### 步骤3：优化Prompt
- 根据测试结果优化Prompt
- 根据用户反馈优化Prompt
- 根据性能指标优化Prompt

### 步骤4：输出Prompt设计结果
- 汇总Prompt设计结果
- 生成Prompt设计文档

## 示例

### 系统Prompt模板
```
你是一个智能写作助手，帮助用户生成文章、报告等内容。

你的任务是：
1. 理解用户的需求
2. 根据需求生成符合要求的内容
3. 确保内容的质量和可读性

注意事项：
- 内容要符合用户的要求
- 内容要准确、清晰、有条理
- 内容要避免抄袭和错误
```

### 用户Prompt模板
```
帮我生成一篇关于{主题}的文章，要求：
1. 字数：{字数}字
2. 风格：{风格}
3. 结构：{结构}
```

### 示例Prompt模板
```
示例1：
主题：人工智能
字数：800字
风格：专业
结构：引言、正文、结论

生成结果：
（略）
```

---

## 注意事项
- Prompt设计应基于产品实际需求
- Prompt设计应考虑用户体验
- Prompt设计应定期优化和更新
- Prompt设计应测试和验证
