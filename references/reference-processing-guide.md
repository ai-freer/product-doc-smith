# 参考资料处理指南

## 参考输入方式

当你撰写需求时，如果需要参考外部文档、知识库或网页链接，可以：

### 1. 直接粘贴参考内容
- 将参考文档的关键内容直接粘贴到对话中
- 智能体会提取关键信息并整合到文档中
- 适用于：参考内容较短、关键信息明确的情况

### 2. 提供本地文件路径
- 如果参考文档在你的本地，提供文件路径
- 智能体会读取文件内容
- 示例："参考文档位于 ./docs/best-practices.md"
- 适用于：参考内容较长、需要完整内容的情况

### 3. 提供网页链接
- 提供参考文章、文档的URL链接
- 智能体会访问网页并提取关键信息
- 示例："参考：https://example.com/best-practices"
- 适用于：在线文档、博客文章、官方文档等

### 4. 提供知识库/文档库链接
- 如果有内部知识库或文档库，提供访问路径
- 智能体会根据指引访问相关资源
- 示例："参考公司知识库：/kb/product/prd-guidelines"

## 参考资料处理流程

无论参考来源是什么，都遵循以下处理流程：

1. **读取参考内容**
   - 本地文件：使用文件读取工具获取内容
   - 网页链接：访问网页提取关键信息
   - 直接粘贴：解析用户提供的内容

2. **验证参考可靠性**
   - 检查参考来源是否可靠（权威网站、官方文档、公司内部文档等）
   - 对于网络搜索结果，优先参考官方网站、知名技术社区
   - 对于用户提供的内容，标注"[用户提供]"

3. **提取关键信息**
   - 提取与当前文档相关的内容
   - 过滤无关信息，保持参考内容的精简性
   - 识别可复用的结构、表述、案例

4. **整合到文档**
   - 将参考内容整合到合适的章节
   - 在文档中标注参考来源，如"[参考: xxx文档]"、"[参考: https://example.com]"
   - 对于权威来源（如官方文档），可直接引用；对于非权威来源，建议验证后使用

5. **标注参考来源**
   - 在文档中明确标注引用的参考
   - 格式：`[参考: 来源]` 或 `[参考: 网页链接]`
   - 示例：`[参考: https://developer.mozilla.org/...]`
