# 流程标准动作

## 1. 产品类型识别和章节选取

在文档生成过程中，需要智能识别产品类型，以便选择合适的专用章节。

### 执行步骤

1. **识别产品类型**（参考：见 [product-type-identification.md](product-type-identification.md)）
   - 分析产品描述关键词
   - 分析产品核心诉求
   - 询问用户确认（如不明确）

2. **判断是否需要专用章节**
   - 如果是传统产品 → 跳过章节选取步骤
   - 如果是AI产品、Agent产品或AI+Agent混合产品 → 继续执行章节选取

3. **执行章节选取**（参考：见 [chapters/selection-rules.md](chapters/selection-rules.md)）
   - 读取相应的专用章节库：
     - AI产品专用章节：`chapters/ai-product/`
     - Agent产品专用章节：`chapters/agent-product/`
   - 根据有价值章节选取规则，评估每个专用章节
   - 智能决策选取有价值的章节：
     - 高价值 + 高匹配 → 选取
     - 高价值 + 低匹配 → 调整后选取
     - 低价值 + 高匹配 → 询问用户
     - 低价值 + 低匹配 → 不选取
   - 对于边界情况的章节，询问用户是否需要

4. **融合章节到文档**
   - 将选取的章节融合到文档框架中
   - 确保章节顺序合理
   - 确保章节层级正确

---

## 2. 外部参考检查

检查用户是否提供了外部参考（文档、链接、知识库等）。

### 执行步骤

1. **检查外部参考**
   - 检查用户是否提供了外部参考（文档、链接、知识库等）

2. **处理参考内容**（参考：见 [reference-processing-guide.md](reference-processing-guide.md)）
   - 如果有外部参考：
     - 按照参考资料处理流程读取、验证、提取、整合参考内容
     - 将外部参考作为修改的依据
     - 在文档中标注参考来源：`[参考: 来源]`
   - 如果没有外部参考：
     - 继续下一步
