# Discovery PRD

## Discovery PRD

### Context & Problem Statement

**What's the current situation?**
Describe the current state of the problem space. What are users experiencing? What's happening in the market?

**What's the problem we're trying to solve?**
Define the problem in 1-2 clear sentences. Focus on user pain points, not solution ideas.

**Why does this matter now?**
Explain the urgency and importance. Why solve this now rather than later?

### Hypothesis

**Primary Hypothesis**
State the core hypothesis you want to validate. Format as:
*"If we [do X], then [Y will happen] because of [Z]."*

**Key Assumptions**
List the critical assumptions underlying this hypothesis. What must be true for this to work?

---

### Evidence & Insights

**Existing Data**
What data do you already have that supports this problem? (Metrics, user research, market data, etc.)

**User Research**
What have you learned from talking to users? Quotes, interviews, observations.

**Market Analysis**
What are competitors doing? What are industry trends?

**Gaps in Knowledge**
What don't we know yet? What questions need to be answered?

---
