# 产品类型识别

## 产品类型分类

### 1. 传统产品
- **特征**：不涉及AI能力或Agent能力
- **示例**：电商网站、SaaS工具、管理系统
- **专用章节**：无

### 2. AI产品
- **特征**：主要提供AI能力（理解、推理、生成等）
- **示例**：AI写作助手、AI翻译工具、AI图像生成
- **专用章节**：AI能力评估、模型选型、端云方案设计、Prompt设计、模型性能评估、成本分析

### 3. Agent产品
- **特征**：自主执行任务、调用工具、规划能力
- **示例**：数据分析Agent、自动化Agent、智能客服Agent
- **专用章节**：Agent能力评估、Agent架构设计、工具调用能力、记忆机制、规划能力

### 4. AI+Agent混合产品
- **特征**：同时包含AI能力和Agent能力
- **示例**：智能写作Agent、智能客服Agent
- **专用章节**：AI产品专用章节 + Agent产品专用章节

## 识别方法

### 步骤1：分析产品描述关键词
- **AI关键词**：生成、理解、推理、大模型、GPT、Claude、Prompt等
- **Agent关键词**：自主、自动、工具调用、规划、记忆、执行任务等

### 步骤2：分析产品核心诉求
- 如果核心诉求是内容生成、理解等 → AI产品
- 如果核心诉求是自主执行任务、调用工具等 → Agent产品
- 如果两者都有 → AI+Agent混合产品

### 步骤3：询问用户确认
- 如果产品类型不明确，询问用户确认
- 示例："这个产品主要提供AI能力还是自主执行任务的能力？"
